Pertanyaan yang Sering Diajukan
Bagaimana cara menambah batch produksi baru di sistem?
Masuk ke halaman Operasional, lalu klik tombol "+ Batch Baru" di bagian Proses Produksi. Isi formulir dengan data input limbah, jenis produk, dan tanggal mulai. Sistem akan otomatis membuat ID batch dan memindahkan ke kolom "Dalam Proses" pada kanban.
Mengapa efisiensi batch saya di bawah 70%?
Efisiensi di bawah 70% biasanya disebabkan beberapa faktor: (1) Kandungan non-organik terlalu tinggi pada limbah masuk, (2) Rasio C/N tidak optimal — idealnya 25–30:1, (3) Kelembaban terlalu tinggi/rendah (optimal 50–60%), (4) Aerasi tidak mencukupi selama proses. Cek dashboard Analitik untuk melihat tren per batch dan identifikasi pola penyebabnya.
Bagaimana cara merespons permintaan buyer di Marketplace?
Buka halaman Marketplace, tab Pesanan. Permintaan baru akan berstatus "Menunggu Konfirmasi". Klik baris pesanan untuk melihat detail, lalu pilih Terima atau Tolak. Jika diterima, sistem akan otomatis mengurangi stok dan membuat dokumen pengiriman.
Bagaimana cara mengupdate stok hasil olahan?
Stok diperbarui otomatis saat batch selesai (stok bertambah) atau saat pengiriman dikonfirmasi (stok berkurang). Untuk koreksi manual, masuk ke Operasional → Stok Hasil Olahan, klik ikon edit pada baris produk, lalu masukkan jumlah koreksi beserta alasannya.
Bagaimana cara mengunduh laporan produksi bulanan?
Buka halaman Riwayat, klik tombol "Export CSV" di filter bar. Untuk laporan PDF lengkap bulanan, buka halaman Analitik, pilih periode "Bulan Ini" atau bulan sebelumnya, lalu klik ikon cetak di pojok kanan atas kartu laporan.
Apakah data produksi bisa diedit setelah batch ditandai selesai?
Data batch yang sudah selesai hanya bisa diedit oleh Admin dalam 48 jam setelah penandaan selesai. Setelah itu data dikunci untuk menjaga integritas laporan. Jika ada koreksi yang diperlukan, hubungi admin SELARAS melalui menu Hubungi Support di bawah.
Bantuan Teknis
Sistem tidak bisa login — apa yang harus dilakukan?
Coba langkah berikut: (1) Pastikan koneksi internet stabil, (2) Clear cache browser (Ctrl+Shift+Del), (3) Gunakan browser terbaru (Chrome/Firefox/Edge), (4) Cek apakah email dan password sudah benar — gunakan fitur "Lupa Password" jika perlu. Jika masih gagal, hubungi admin di support@SELARAS.id.
Data di dashboard tidak ter-update secara real-time
Dashboard diperbarui setiap 5 menit. Untuk refresh manual, tekan tombol F5 atau klik ikon reload di browser. Jika data tetap stale lebih dari 15 menit, coba logout dan login ulang untuk memuat ulang session.
Export CSV gagal atau file kosong
Pastikan ada data yang sesuai dengan filter aktif sebelum export. Jika filter terlalu ketat (misal kombinasi tanggal + jenis + status yang tidak ada datanya), hasilnya akan kosong. Reset filter terlebih dahulu, lalu coba export kembali. Pastikan browser mengizinkan unduhan file dari situs ini.
